## Objective
Develop an automated solution to identify and terminate inactive blocking sessions in Oracle EBS environments.

- Shell Scripting
- Linux

- Blocking Session Detection
- Session Monitoring
- Automated Session Kill
- Email Alert Mechanism
- Continuous Monitoring

## Skills Used
- Oracle SQL
- Shell Scripting
- Automation
- Database Monitoring

## Outcome
Reduced manual DBA intervention and improved database availability through automated blocking session handling.
